# Changelog / 変更履歴

## Unreleased
- (EN) `oep.probe.config` item `disable` (0x07, oep-spec 6088438; `src/registry.js` resynced): `new Disable({ channel })`, removed with `remove('disable', ch)` / `unset([['disable', ch]])`, in `canonical` / `canonicalHash`; a channel the probe never uses or touches, so every request naming it is `Unavailable` with `cause` `held_by_settings` and the channel. The page's settings tab has a "disable channels" form (a comma list) and lists / removes the items. Tests against the Python fake: refusals with cause 5 (plan_apply, settings plan, slot, attach pins / reset, scan, gpio set / read), scan count 0 skipping, cause 1 when in use, idle + disable malformed, unset enabling again.
- (JA) `oep.probe.config` の項目 `disable`（0x07、oep-spec 6088438。`src/registry.js` を写し直した）: `new Disable({ channel })`。`remove('disable', ch)` / `unset([['disable', ch]])` で消す。`canonical` / `canonicalHash` に入る。probe が一切使わず触れない channel で、それを指す要求は channel 付きの `Unavailable`（`cause` は `held_by_settings`）。ページの設定タブに「使わない channel」のフォーム（カンマ区切り）を足し、項目の一覧と削除にも出る。Python の fake に対するテスト: cause 5 の断り（plan_apply、設定の plan、スロット、attach の pins / reset、scan、gpio の set / read）、scan の count 0 が飛ばすこと、使用中は cause 1、idle と disable は malformed、unset で戻ること。
- (EN) Breaking: the wire follows oep-spec's zero-base rewrite of 2026-10-01 (faddb4e; docs/v1-zero-base-proposal.ja.md §3 / §7; `src/registry.js` resynced: `COMMON`, `USB`, `LIMITS`, `expired`, `discoverable`). Every answer that ended in data or a list carries its length and may be followed by TLVs: read answers `start flags len data [TLV]` (console, fixture UART; capture `len` u32), gpio read `n n×level`, dmi `done status nvals values`, arm-adi transfer `done status ack nvals values`, run `status stopped dpc elapsed_us nvals values` (stopped 2 = the hart could not be halted: `RunResult.notHalted`), data frames `position len data [TLV]`, events `kind fixed-part [TLV]`, the heartbeat `boot_id uptime_ns`. TLVs have a long form (`tag 0xFF len(u16) value` for 255 bytes and more; `message.tlv` / `splitTlvs`, a short value in the long form is `BadTlv`). confirm answers the probe's `boot_id` (`Host.limits.bootId`); subscribe's `max_delay_ms` is u32; `rejected unsupported` is always `tag [TLV]` (0x00 = a fixed-part value: `Unsupported.tag` null, `.tlvs` / `.channel` / `.index` / `.fn`); `channel_group` is `group n n×(role channel)`; describe is cached per boot (`Host.describes`, `core.maxOpMs`); `probeInfo` has `discoverable` (was `oepPid`) and `maxOpMs`, `planRoles` is u32.
- (JA) 破壊的変更: wire を oep-spec の 2026-10-01 のゼロベース見直し（faddb4e。docs/v1-zero-base-proposal.ja.md §3 / §7。`src/registry.js` を写し直した: `COMMON`、`USB`、`LIMITS`、`expired`、`discoverable`）に揃えた。データや並びで終わっていた応答はすべて長さを持ち、後ろに TLV を置ける: read の応答 `start flags len data [TLV]`（console、fixture UART。capture の `len` は u32）、gpio read `n n×level`、dmi `done status nvals values`、arm-adi transfer `done status ack nvals values`、run `status stopped dpc elapsed_us nvals values`（stopped 2 = hart を止められなかった: `RunResult.notHalted`）、データフレーム `position len data [TLV]`、出来事 `kind 固定部 [TLV]`、ハートビート `boot_id uptime_ns`。TLV に長い形（255 byte 以上は `tag 0xFF len(u16) value`。`message.tlv` / `splitTlvs`、短い値の長い形は `BadTlv`）。confirm は probe の `boot_id` を返す（`Host.limits.bootId`）。subscribe の `max_delay_ms` は u32。`rejected unsupported` は常に `tag [TLV]`（0x00 = 固定部の値: `Unsupported.tag` は null、`.tlvs` / `.channel` / `.index` / `.fn`）。`channel_group` は `group n n×(role channel)`。describe は起動ごとに cache（`Host.describes`、`core.maxOpMs`）。`probeInfo` に `discoverable`（`oepPid` から改名）と `maxOpMs`、`planRoles` は u32。
- (EN) Breaking: after the lease lapsed, the same session id's next request is `rejected expired` (0x0E): `Expired` (extends `Rejected`) with `.leaseMs`, never re-opened silently; `open()` then answers `resumed` 2 (`Opened.resumed` is a number now, `.swept`) and `Host.epoch` moves (as on `no_session`, what an id forced out by another meets after `Locked`). `Wire.connections()` and `Console.streams()` page through `first` / `more`. A subscribe to an fn that emits nothing is `Unsupported`; an unsubscribe of nothing is ok.
- (JA) 破壊的変更: lease が切れた後の同じ session_id の要求は `rejected expired`（0x0E）: `Expired`（`Rejected` の下、`.leaseMs` つき）。黙って open し直さない。その後の `open()` は `resumed` 2 を返し（`Opened.resumed` は数になった。`.swept`）、`Host.epoch` が進む（`no_session` でも進む。force で奪われた側は `Locked` のあと no_session）。`Wire.connections()` と `Console.streams()` は `first` / `more` でページを辿る。送り出さない fn の subscribe は `Unsupported`、購読の無い unsubscribe は ok。
- (EN) Breaking: `oep.probe.config` - describe is declarations only (`ProbeConfig.describe()` -> `Declared`: `storageBytes`, `items`, `slotsMax`, `bindModes` from a u32); the live storage / slot / bind state is the lock-free `state` op (0x06, paged; `ProbeConfig.state()` -> `State`, `SlotState.lastTryAtNs` bigint); `unset` (0x05) removes items by key (`ProbeConfig.unset([[kind, key]])`; `remove(kind, key)` now makes a `Removal` that `set()` sends as an unset after its set - a key-only item no longer removes); the new `Uart` item (`{ fn, baud, format }`, tag 0x06) is applied whenever that UART's plan has RX or TX; slot fields are `retry_ms` u32 (`Slot.retryS` stays, seconds) and `max_speed_hz` u32 (`Slot.maxSpeed` stays, Hz); mechanism `none` (0xFF) = a slot without a console; `canonical` sorts plans by (fn, role, channel) and `canonicalHash` is the CRC-32 of the one TLV encoding; `get()` reads again when the hash moved between pages. The page's settings tab reads `describe()` + `state()` and adds the UART item form; the probe line shows discoverable / max op ms.
- (JA) 破壊的変更: `oep.probe.config` - describe は宣言だけ（`ProbeConfig.describe()` -> `Declared`: `storageBytes`、`items`、`slotsMax`、u32 の `bindModes`）。保存・スロット・bind の今の状態はロック不要の `state` op（0x06、ページング。`ProbeConfig.state()` -> `State`、`SlotState.lastTryAtNs` は bigint）。`unset`（0x05）はキーで項目を消す（`ProbeConfig.unset([[kind, key]])`。`remove(kind, key)` は `Removal` を作り、`set()` は set の後に unset として送る。キーだけの項目で消す規則は廃止）。新しい `Uart` 項目（`{ fn, baud, format }`、tag 0x06）は、その UART の plan に RX / TX が付くたびに掛かる。スロットのフィールドは `retry_ms` u32（`Slot.retryS` は秒のまま）と `max_speed_hz` u32（`Slot.maxSpeed` は Hz のまま）。mechanism `none`（0xFF）= コンソール無しのスロット。`canonical` は plan を (fn, role, channel) で並べ、`canonicalHash` は一意の TLV 符号化の CRC-32。`get()` はページの間で hash が動けば読み直す。ページの設定タブは `describe()` + `state()` を読み、UART 項目のフォームを足した。probe の行に discoverable / max op ms。
- (EN) Breaking: wires - `attach_under_reset` (op 0x04) is gone: `Wire.attach({ reset: [channel, holdMs] })` sends the attach's critical TLV 0x05 (`attachUnderReset()` stays as a wrapper and returns the dpc from the answer's TLV 0x11; `Wire.halted` / `.dpc` / `.flags`); `max_speed` is required by the probe, so `attach()` always sends one (none: the wire's declared `max_clock_hz`, else 1 MHz; `attachBody()` is async); the answer's flags are the common `attach_flags` (`ATTACH_FLAGS`; swd's dormant bit moved to bit2); scan takes `{ maxSpeed, idleClock }` TLVs and its skip is TLV 0x02; a non-reset channel is `Unsupported` tag 0x85. `RiscvDm.run({ timeoutMs: null })` is the probe's `max_op_ms`, no longer 0xFFFFFFFF (`NO_TIMEOUT` removed; `runBody` needs a number); `runResult(result)` counts its own values.
- (JA) 破壊的変更: 線 - `attach_under_reset`（op 0x04）は無くなり、`Wire.attach({ reset: [channel, holdMs] })` が attach の critical TLV 0x05 を送る（`attachUnderReset()` は包みとして残り、応答の TLV 0x11 の dpc を返す。`Wire.halted` / `.dpc` / `.flags`）。probe は `max_speed` を必須にしたので `attach()` は常に送る（無ければその線の宣言の `max_clock_hz`、無ければ 1 MHz。`attachBody()` は async）。応答の flags は共通の `attach_flags`（`ATTACH_FLAGS`。swd の dormant は bit2 に移った）。scan は `{ maxSpeed, idleClock }` の TLV を取り、skip は TLV 0x02。reset の線でない channel は `Unsupported` tag 0x85。`RiscvDm.run({ timeoutMs: null })` は probe の `max_op_ms` で、0xFFFFFFFF ではなくなった（`NO_TIMEOUT` を外した。`runBody` は数が要る）。`runResult(result)` は値の数を応答から読む。
- (EN) Breaking: console - marks carry `timeNs` (u64 bigint, the probe's one clock; `MARK_BYTES` 22), `MARK_KIND` / `MARK_NAMES` / `MARK_DETAIL` / `READ_FLAGS` and `PositionStream.FROM_*` come from `registry.COMMON.enum`, mark `closed` (0x09) with why, the lock-free `streams()` op (`StreamInfo`), `Console.NONE` (0xFF), a write that fits nothing is completed failed (`StreamIO.write` waits on it), `Chunk.tail`. `StreamIO` reads fit `frame - 16`.
- (JA) 破壊的変更: console - マークは `timeNs`（u64 の bigint、probe の 1 本の時計。`MARK_BYTES` 22）。`MARK_KIND` / `MARK_NAMES` / `MARK_DETAIL` / `READ_FLAGS` と `PositionStream.FROM_*` は `registry.COMMON.enum` から。マーク `closed`（0x09）に理由。ロック不要の `streams()` op（`StreamInfo`）。`Console.NONE`（0xFF）。何も入らなかった write は completed failed（`StreamIO.write` はそれを待つ）。`Chunk.tail`。`StreamIO` の読みは `frame - 16`。
- (EN) Breaking: capture - every start is a generation (u32): `start()` sets `LogicCapture.generation`, `status()` -> `{ state, segmentsDone, writePos, flags, generation, error, errorName, dropped }`, segment records are 37 bytes (`Segment.generation`), `read(position, length, generation?)` / `release(serial, generation?)` name it (default: the one seen at start / status; a host that did not start it asks status), `readSegment(segment)` passes the segment's own, streaming pushes carry TLV generation (`unpackPush`, `Push.generation`; `stream()` drops another generation's: `Received.stale`); `segments()` follows `more` (`segmentsPage`); trigger values are u32; `CROSS_UP` / `CROSS_DOWN` and `FRONTEND` are the analog's; `Calibration.vrefint.nominalMv`, factory data has `raw_len`; `CaptureGroup.start()` reads each track's generation (`.generations`); group events are triggered 0x03 / stopped 0x02; a bind of an fn not in `tracks` is `Unsupported` (`.fn`).
